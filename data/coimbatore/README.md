# Coimbatore route-safety seed data

## Official municipal source

- Source: Coimbatore City Municipal Corporation, Kovai Junction Transformation Programme
- Page: https://www.ccmc.gov.in/index.php/createpage/kovai-junction-transformation-programme
- Retrieved: 2026-08-23
- Local source image: `30-critical-intersections.png`

The municipality states that the programme selected 30 critical intersections using accident history, conflict points, blackspots, and broader safety concerns. The source image distinguishes junction-improvement locations (blue) from black-spot study/design locations (red).

Visible red black-spot study/design labels:

1. Arul Migu Thirukoil
2. Vellalore Road

The image also labels multiple junction-improvement locations, including KNG Pudur, Edayarpalayam, Ajanoor–Vedapatti, Nallampalayam, Sanganur–Sivananda Colony, Ramakrishna Nagar, Villankurichi, Kalanatti, S Bend, Tidel Park, Tatabad 6th Corner, Power House, Chinthamani, District Court, Lanka Corner, GV Residency Junction, SIHS Colony–Trichy Road Junction, Telungupalayam, Shivalaya, Sundakkamuthur, Kurichi Pirivu, Sarada Mill Junction, Puttuviki, and Palakkad–Kurichi Pirivu.

## Fitness for use

This asset is suitable only as a prototype seed and source reference. It is **not yet training data** because it lacks exact coordinates, dates, crash counts, severity labels, exposure/traffic volume, and an explicit machine-readable licence. Before model training, obtain a machine-readable export or written data permission from CCMC/Tamil Nadu GIS, geocode and manually validate every junction, and add historical outcome labels.

Do not represent routes that avoid these locations as guaranteed safe.
